# FPS Pro v9.1 - Quick Reference Card

## 🎮 Menu Access
**SELECT + DPAD_UP** → Open/Close Menu

---

## 🎯 Default Controls

| Feature | Button | Mode |
|---------|--------|------|
| **Anti-Recoil** | RT | Hold |
| **Slide Cancel** | RB | Hold |
| **Snaking** | LB | Toggle |
| **Wall Bounce** | X | Hold |
| **Drop Shot** | RT+B | Hold |
| **Bunny Hop** | L3 | Hold |
| **Weapon Swap** | Y | Hold |
| **Auto Sprint** | Auto | Always |

---

## 📱 Menu Navigation

```
DPAD_UP/DOWN    → Navigate options
DPAD_LEFT/RIGHT → Change values
SELECT          → Save & Exit
```

---

## 💡 LED Colors

| Color | Status |
|-------|--------|
| 🔵 Blue | Ready |
| 🔷 Cyan | 1 Active |
| 🟢 Green | 2 Active |
| 🟠 Orange | 3+ Active |
| 🟡 Yellow | Menu Open |

## ⚡ Quick Tips

1. **Start Simple** - Enable one feature at a time
2. **Tune Recoil** - Adjust per weapon (15-40)
3. **Avoid Conflicts** - Don't use Snaking + Drop Shot together
4. **Save Often** - Exit menu properly to save settings
5. **Test First** - Try in practice mode before live games

---

## 🔧 Common Adjustments

### Recoil Too Strong?
Menu → Option [3] → Decrease to 15-20

### Auto Sprint Triggering Early?
Menu → Option [23] → Increase threshold to 70-80

### Bunny Hop Too Fast?
Menu → Option [19] → Increase interval to 150+

## ⚠️ Troubleshooting

**Menu won't open?**
→ Hold DPAD_UP, then press SELECT

**Features not working?**
→ Check enabled in menu (option [0], [5], [8]...)

**Settings not saving?**
→ Always exit with SELECT button
